# Failure modes

|     | What breaks                                                         | Fix                                                                                                                                                                                        |
| --- | ------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| M0  | Same field edited on two devices                                    | Conflict proposal; both values kept (Sync merge rules)                                                                                                                                     |
| M0  | Retry after a dropped socket, even months later                     | Per-client high-water mark, kept permanently                                                                                                                                               |
| M0  | Laptop offline past the 90-day log                                  | Snapshot, then pending changes rebased with their base hashes                                                                                                                              |
| M0  | Vault deleted or a bad checkout                                     | Daemon pauses above 50 notes / 10%; tombstones for 30 days                                                                                                                                 |
| M0  | An agent edits vault files directly                                 | The Claude Code hook blocks Edit, Write and shell commands on the vault path. Other writers are "unattributed": they sync, but can't verify, approve, loosen privacy or change permissions |
| M0  | Vault copied to another laptop                                      | `state.db` names its owning device; the copy discards the copied queue and repairs from files vs server, so nothing replays twice                                                          |
| M0  | Machine restored from a week-old backup                             | `hello` shows a last `clientSeq` below the server's mark: reset, new `clientId`, repair; no edit dropped                                                                                   |
| M0  | An agent moves a note out of `facts/` to edit it without a hold     | The hold is keyed on type, and moves out of held areas are held                                                                                                                            |
| M0  | One blocked mutation stalls the queue                               | Every result consumes its `clientSeq`; the edit moves to blocked                                                                                                                           |
| M0  | A verified field edited in Obsidian                                 | The edit stays in the file as "not synced: needs approval"; approving it syncs it                                                                                                          |
| M0  | An agent approves its own held change                               | Agents can only withdraw their own proposals; deciding is human-only                                                                                                                       |
| M0  | Mutation 12 arrives before 11                                       | Strict in-order apply: the gap is refused, the client resends 11 then 12                                                                                                                   |
| M0  | A note made sensitive still shows up in a normal search             | Chunks moved in the same transaction; every hit re-checked against the current class and scopes                                                                                            |
| M0  | An agent reads a passport scan to get the number                    | Every upload starts unclassified and agent-invisible; vault documents never give agents text, images or URLs                                                                               |
| M0  | A local agent reads grades or a passport scan straight off the disk | Sensitive notes stay in the cloud by default; vault files never written to disk; the hook blocks Read, Grep and Glob on sensitive folders, `documents/files/`, `unorganized/` and `inbox/` |
| M0  | An agent creates a new note that supersedes a verified score        | Superseding creates of held types are held like edits                                                                                                                                      |
| M0  | Both passkeys lost                                                  | Sign-in plus a 72-hour wait with notices before a new passkey can approve                                                                                                                  |
| M0  | OAuth bug in our self-hosted server                                 | Conformance tests (MCP Inspector, the claude.ai connector, Claude Code), audience-bound tokens, refresh rotation; managed fallback ready                                                   |
| M0  | An agent clears `verified`, then edits the value                    | Approvals are judged on the transaction's effect against the DO's own verification records                                                                                                 |
| M0  | An editor saves in the instant before a sync write                  | Atomic swap that keeps the displaced file; a surprise version becomes your pending change; displaced versions kept 7 days for `brainiac restore`                                           |
| M0  | `state.db` lost on a laptop                                         | Files kept; repair diffs files against the server into pending changes or conflicts                                                                                                        |
| M0  | YAML reformatted on save                                            | Raw text is stored; patches preserve comments, order and quoting                                                                                                                           |
| M0  | Crash between commit and indexing                                   | Transactional jobs outbox + alarm re-dispatch                                                                                                                                              |
| M0  | Old ingest result lands after a newer edit                          | Installed only if the note revision still matches                                                                                                                                          |
| M0  | One user reads another's data                                       | Separate DO per record; base id from the session; cross-tenant suite                                                                                                                       |
| M0  | A token without sensitive scope sees a grade in a snippet           | Privacy-class chunk families; canary tests                                                                                                                                                 |
| M0  | An agent or client fakes a confirmation                             | Approvals need a passkey in a signed-in session, bound to the diff                                                                                                                         |
| M0  | Deploy changes the DO SQL schema                                    | Lazy per-object migrations, additive for one release, tested on fixture shapes                                                                                                             |
| M0  | Old CLI writes with an older schema                                 | `hello` version check: read-only until upgraded                                                                                                                                            |
| M0  | `Résumé.md` vs `Résumé.md` (NFC/NFD), `CV.md` vs `cv.md`            | NFC normalization and case-insensitive clash checks on every path                                                                                                                          |
| M0  | Corrupt local index                                                 | `brainiac repair` rebuilds it from files + server, keeping pending changes                                                                                                                 |
| M1  | Prompt injection in an uploaded PDF                                 | The approval list blocks every leaking or destructive action; filer runs are propose-only with no shell or network                                                                         |
| M1  | A model misquotes a number                                          | `ask` returns canonical values; `verify` catches mismatches; the site itself only answers deterministic questions                                                                          |
| M1  | Your Claude is unavailable (limit hit, outage)                      | Brainiac needs no model to run: the site, sync, search, review and questions keep working; inbox items wait                                                                                |
| M1  | Two agents file the same inbox item                                 | Inbox leases: one agent per item                                                                                                                                                           |
| M1  | Extraction fails on a scan                                          | Retries, then "unreadable" with a question; file stays viewable                                                                                                                            |
| M1  | Huge or hostile upload                                              | Byte sniffing, caps, decompression limits, executables rejected                                                                                                                            |
| M1  | Email-in spam or a spoofed sender                                   | Verified-sender allowlist, quarantine for everything else                                                                                                                                  |
| M1  | An agent loop hammers the record                                    | Per-token rate limits; the DO sheds load with 429 and Retry-After                                                                                                                          |
| M2  | Repo renamed or deleted                                             | Tracked by `repo_id`; deletion marks it archived and keeps the snapshot                                                                                                                    |
| M2  | Connector token expires                                             | Status turns red, a question asks you to reconnect                                                                                                                                         |
| M3  | Secret exfiltration through a command                               | Agents get no secret injection into commands; only `fill_form` to the saved domain                                                                                                         |
| M3  | Form fill on a lookalike domain                                     | Domain bound to the secret, user gesture required                                                                                                                                          |
| M3  | Two devices create incompatible versions of one type                | Schema conflict, never a union                                                                                                                                                             |
|     | Neon unavailable                                                    | Only sign-in and billing need it; live sessions keep working                                                                                                                               |
|     | Cloudflare-wide incident                                            | Local copies keep working; exports; stated plainly (see "Security")                                                                                                                        |
|     | Alchemy renames a resource                                          | Pinned version, plan diff reviewed in CI, stateful resources protected                                                                                                                     |
