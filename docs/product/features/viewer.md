# Viewer

Every note and file opens in one pane with its metadata (type, issuer, expiry, what it proves) beside it. T3 Code (MIT) already renders markdown, code, diffs, PDFs, Office files and tables well. Brainiac depends on the same public libraries and copies T3's small glue files with the MIT notice.

| Kind                                      | Renderer (as in T3 Code)                                                                                                                                                                                           | Safety                                                       |
| ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------ |
| **Markdown note**                         | `unified` 11 + `remark-parse`, `remark-gfm`, `remark-math` (KaTeX), GitHub alerts, then `rehype-sanitize`, rendered via `hast-util-to-jsx-runtime` with a parse cache. Front-matter shows as a form above the body | Raw HTML stripped by the sanitizer allowlist                 |
| **Code, JSON, YAML**                      | `@pierre/diffs` with `@pierre/highlights` WASM lexers (Apache-2.0)                                                                                                                                                 | Size cap, then streaming                                     |
| **Diffs** (proposals, history, approvals) | `@pierre/diffs`                                                                                                                                                                                                    | n/a                                                          |
| **Folder tree**                           | `@pierre/trees` with search                                                                                                                                                                                        | n/a                                                          |
| **PDF**                                   | `pdfjs-dist` 6.4 with its text layer; citations open the page with the value highlighted                                                                                                                           | From `usercontent.<domain>`, scripting off                   |
| **Word, Excel, PowerPoint**               | T3's OpenXML viewer (`@betteroffice` engines), each format laid out and painted in its own web worker, entirely in the browser                                                                                     | Macros never run: the VBA project never reaches an engine    |
| **CSV, large text**                       | Virtualized table; worker-backed text viewer                                                                                                                                                                       | n/a                                                          |
| **Images, audio, video**                  | Worker image decoding; native players, playing the bytes fetched once from memory (a file link opens once, so a player can't range-request it)                                                                     | Re-encoded thumbnails; EXIF stripped from downloads          |
| **HTML file**                             | Sandboxed iframe on `usercontent.<domain>`                                                                                                                                                                         | No scripts by default, strict CSP, no cookies on that domain |
| **Note editing**                          | The body is edited as markdown source (CodeMirror 6) with the unified preview beside it, so your text is never re-serialized. Fields use a schema-driven form that patches only the YAML node it changes           | Validated as you type                                        |
| **Secrets**                               | Name, policy, last use; the value only after a passkey check                                                                                                                                                       | Never to agents                                              |

Navigation: the folder tree, a table per type with filters, a one-hop graph around the open note, a timeline, and a command palette (`⌘K`: titles in memory, then search, then `ask`). The PWA uses the same viewer on phones.
