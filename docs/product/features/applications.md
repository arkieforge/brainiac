# Applications

| Phase | Feature                                                                                                                                                                                                                                                                                        |
| ----- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| M2    | **Application tracker**: target, deadline, portal, status (`researching → preparing → submitted → interview → decision`), requirement checks (see "Structure"), missing items as questions                                                                                                     |
| M2    | **CV and resume**: academic CV, one-page resume and Europass, from facts, rendered with Typst templates. "Tailor" picks and orders facts per target; submitted versions are frozen on the application                                                                                          |
| M2    | **Documents and expiry**: issuer, issue and expiry dates, the fields each document proves; an item expiring within 60 days is flagged on it and on each open application relying on it, and emailed at 60, 30, 7 and 0 days (per-DO alarms), until the person turns reminders off on `/emails` |
| M2    | **Packets**: the files a portal wants, named its way, as a zip                                                                                                                                                                                                                                 |
| M2    | **Letters, status only**: Referee and Letter notes (to-ask, requested, sent, received); a letter still owed is a question to you. The letter itself goes through the institution's own system                                                                                                  |
| M3    | **Writing from facts**: SOPs, cover letters, essays, every claim cited, decisions respected                                                                                                                                                                                                    |
| later | **Sealed letters** stored by Brainiac and delivered to institutions (needs delivery integrations and a legal review of access rights)                                                                                                                                                          |
| later | **Photos to spec** (passport 35x45 mm, US visa 2x2 in), background removal                                                                                                                                                                                                                     |
