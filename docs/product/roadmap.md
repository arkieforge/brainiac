# Roadmap

Four phases, each usable on its own. M0 is private (dogfooded by the team on their own records); outside users arrive after M1, once the eval gates pass. Authorization, approvals, audit and the cross-tenant and canary suites ship before the first remote MCP. Sizes are relative; week estimates come after M0, when sync and the daemon have been built once.

| Phase                             | Ships                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          | MCP tools                                                     | Size    |
| --------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- | ------- |
| M0 **Record + sync**              | `packages/core`, `base`, `sync`; raw-markdown notes with node-level patching; Base DO; the protocol with high-water marks; the daemon (macOS, Linux); Better Auth sign-in with passkeys, MCP OAuth (CIMD test first) and OAuth conformance tests; passkey approvals; vault storage and the vault-document flag; tokens and scopes; the authorization projection; audit; jobs outbox; cross-tenant and canary suites; site editor (form + CodeMirror) and viewer for markdown, PDF and images (Office, CSV and media in M1); Claude Code plugin, skill and hook | describe, query, get, add, create, update, undo, request_info | largest |
| M1 **Retrieval + filing + trust** | Ingest (`toMarkdown`, embeddings, chunk families); FTS5 + vectors + graph; "file my inbox" (headless Claude Code locally, the connector in the cloud); imports (CV, LinkedIn export, existing OKF vaults); the Windows daemon and its real-filesystem tests; overview and review; detectors; questions; the evals harness; parity, chaos and security suites                                                                                                                                                                                                   | + search, related, ask                                        | large   |
| M2 **Applications**               | Tracker with requirement checks; Typst CVs and resumes; documents and expiry; packets; letters (status); GitHub App; ORCID and DOIs; Polar billing                                                                                                                                                                                                                                                                                                                                                                                                             | + draft                                                       | medium  |
| M3 **Hands-off**                  | The extension's form fill using the vault; structure growth and `organize`; customization; drift checks via treg; links                                                                                                                                                                                                                                                                                                                                                                                                                                        | + organize, fill_form                                         | medium  |

**Later, when real use asks for it**: sealed letters, photos to spec, a public profile page, more connectors (Kaggle, Hugging Face, app stores, Credly), agent-run commands with secrets, hosted form filling, opportunity search, counselor views, the in-site Ask box and hosted filer for API-key users, Vectorize for very large records, rerankers, Neon Realtime if it replaces the DO layer, a native phone app.
